# 知识图谱历史评测汇总

本页集中保存 2026-11-05～11-06 的 33 份旧逐轮报告的版本、计分范围和汇总指标；
其中两份内容完全相同的 c88 报告共用一节。分数与表格沿用原报告，未重新评分。
评分口径见 [实体与关系评测](knowledge-graph-evaluation.md)，方案取舍见 [演进记录](knowledge-graph-history.md)。

旧逐项 Markdown 展开已移除；每节链接保留的本机原始 JSON（含逐片段结果），
这些运行数据不随 Git 上传。离线复现需相应原始数据、代码、标注和策略凭据；当前代码不保证能重放所有历史策略。
人工阅读版、人工取舍、最新逐项报告及独有审计样本仍保留在 docs，入口见评测说明。

这些是开发集的多轮实验。实体匹配要求类型正确；关系 assertion 要求端点身份/类型、谓词、方向和断言一致。
out_of_scope 单列待审，不计 TP/FP；失败和 pending 仍计入召回分母，不能当作全图预测准确率。
严格限定分数会因同义但不同措辞/范围而扣分，须结合原始差异人工解释。
实验名里的 final、selected 不表示最终采用，token 实验的采用结论以演进记录为准。
