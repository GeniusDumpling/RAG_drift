## 操作

| 操作 | 3D 效果 |
|---|---|
| 点击节点 | 自动居中，并将该节点设为三维旋转中心 |
| 拖拽空白区域 | 围绕选中节点上下、左右连续旋转 360°；未选中时围绕当前视图中心 |
| Shift + 拖拽空白区域 | 平移视角 |
| 拖拽球体节点 | 沿当前屏幕平面移动节点，旋转后也可拖拽 |
| 滚轮或加减按钮 | 放大细节或返回默认范围，不能缩小到默认概览之外 |
| 适应画布 | 恢复三维概览和默认观察角度 |
| 悬停节点 | 高亮节点与关联邻居，显示名称和提示 |
| 悬停连线 | 单独高亮连线；点击后在右侧查看字幕证据 |
| 双击节点／展开邻居 | 保留已有图谱数据，加入该实体的邻居 |
| 定位实体 | 从右侧关联详情选择实体，查看入链、出链及关系证据 |

三维模式使用带光照的球体和透视投影，默认关闭名称常显，悬停或选中时显示。数据面板可开启名称常显、调整节点大小、连线粗细及布局引力。名称在屏幕上保持正向，随视角变化移动。

切换维度保留当前查询、筛选条件、已展开的数据和选中内容；重新计算对应维度的布局。三维模式在节点／关系集合变化时重建场景和概览，已有选中节点时再将其居中，避免 WebGL 实例缓冲区扩容时复用失效资源。连线可能因同一对端点存在多种关系而重叠，可通过右侧入链／出链列表逐条选择证据。

浏览器需要支持 WebGL。检测到不支持或三维初始化失败时，页面自动切换为二维并给出提示；也可在工具栏手动重试 3D。

## 数据与实现

- 使用 `@antv/g6@5.1.1` 与官方 `@antv/g6-extension-3d@0.1.23`，采用三维力导向布局、球体、三维连线和光照，参见 [G6 官方 3D 文档](https://g6.antv.antgroup.com/en/manual/further-reading/3d)。
- 三维扩展按需加载。G6 基类集中分块，避免扩展与核心跨块循环依赖；其他页面不会因该分块方式提前加载完整图谱渲染器。
- 球体共享单位几何体，通过实例变换调整大小，减少重复几何体和缓冲区重建。三维交互按完整 XYZ 坐标投影选取，避免二维坐标工具忽略 Z，也避免每次鼠标移动都同步读取 GPU 像素。
- 名称与提示使用 HTML 层，场景销毁时一并清理指针处理、标签、动画帧和 WebGL 画布。
- 三维缩放以适应完整包围球后的概览为下限，放大上限为默认比例的 8 倍；画布尺寸变化后重新适配，并保留已有细节放大。

Neo4j 查询和构图任务不变。继续执行 [连通图谱选取规则](graph-ui-connected-2026-10-26.md)：隐藏少于 5 个节点的独立子图，优先展示关联密集的区域。桌面默认最多 300 节点／500 关系，手动展开最多 500 节点／1,000 关系；移动端最多 150 节点／300 关系。实体检索覆盖全部有效图谱，符合展示规则的结果可显示在任一维度的画布上。
