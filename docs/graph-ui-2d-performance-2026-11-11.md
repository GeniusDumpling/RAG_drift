# 二维图谱文字与逐帧更新优化

当前正式部署已恢复为本页的二维优化版 v2；后续三维弹性联动因性能问题回退，详见[回退记录](graph-ui-3d-drag-rollback-2026-11-12.md)。二维显隐及零逐帧 React 提交已在回退后复验。

二维名称根据屏幕上的节点直径和文字字号显示：节点直径至少 28 CSS 像素，且名称字号缩放后至少 7 CSS 像素时，才显示普通名称。关系名称同时检查两个端点中较小的屏幕直径和自身字号。节点大小滑块、类型大小、关系数量以及缩放都会影响结果。

不可读的名称不会创建 SVG text/tspan，也不执行名称换行。放大后恢复。悬停或选中的节点／关系仍显示名称，字号至少为屏幕上的 10 CSS 像素。显式关闭节点常显名称时仍保留悬停／选中名称；类型样式选择“不显示文字”继续生效。

React 负责结构、选择和设置；`BrowserMotion` 负责 SVG 坐标、路径和文字。力导向 tick、节点拖拽、平移和滚轮缩放通过同一个 requestAnimationFrame 合并更新，不再每帧修改 React 状态。拓扑、节点索引、平行曲线、DOM 元素和名称排版缓存复用；平移缩放不重新计算关系路径。固定、拖动结束等离散操作仍更新 React 控件。

## 验证

40 项图谱测试和生产构建通过。浏览器回归覆盖拖拽固定、解除固定、展开收起、隐藏撤销、字幕证据、类型样式、导出、移动端、维度切换及真实数据，未发现页面脚本异常。

| --- | ---: | ---: |
| 概览中的名称元素 | 637 | 0 |
| 600 ms 布局观察期内 React 提交次数 | 34 | 0 |
| 60 帧滚轮缩放期间 React 提交次数 | 64 | 0 |
| 同次缩放的 CDP ScriptDuration 增量 | 536.492 ms | 237.660 ms |

本次缩放脚本耗时降低约 56%，具体耗时受设备、浏览器和布局状态影响；该指标不代表帧率或所有操作的耗时。性能检查还验证低缩放时选中节点／关系名称保持显示，进一步缩小时普通名称再次移除。
