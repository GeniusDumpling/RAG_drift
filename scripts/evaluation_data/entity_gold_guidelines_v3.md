# 当前实体标注规则

当前答案为[entity_gold_v3.json](entity_gold_v3.json)：20段、中英文各10段，共101条片段内实体记录。`entities`是唯一标准答案；`models`只是来源涉及的型号说明，`notes`可能含历史复核说明，两者不参与评分或传给模型。

- 每个实体只保留`name`、`type`、`mentions`。`mentions`必须是正文逐字出现的叫法，规范名称可写明确所属型号；不能把补全的规范名称冒充原文提及。
- 原文按换行存为字符串数组，不改写字幕；实体答案变化时保留来源、正文和类型口径。型号保留代际和Pro等变体，不擅自补型号。
- 同一对象的多种叫法合并；不同设备的同名部件区分所有者。无法确定身份时保留局部泛称，不凭邻近位置硬绑定。
- 固件标为software；完整遥控器与飞行眼镜标为product，没有型号不改变完整设备的类型。
- 数值、尺寸、价格、帧率和时间不独立建实体；普通动作不逐句建方法。此轮不评属性，也不要求保留所有语言学实体提及。
- 是否值得入图按具体片段人工决定；推测或否定中的实体可以被提及，但不表示关系成立。不核实视频说法的现实真伪。
- 修改答案时先读完整原文，核对漏标、多标、类型及归属；不能只根据待测输出改答案抬高分数。更改答案后按新指纹另存评测结果，不将跨标准分数变化当作模型改进。

[历史24项人工取舍](../../docs/entity-value-selection-review.md)保留供追溯，后续直接修改的当前JSON优先。旧版关系金标准v1与[entity_gold_v1.json](entity_gold_v1.json)的106条实体配套，两者均保留供历史复现；当前关系默认数据以关系工具配置为准，本次不改动关系流程。
