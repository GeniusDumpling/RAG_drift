# 三维节点弹性拖拽

**已回退。** 因联动版本性能不足，正式服务和源码恢复到联动前版本，保留二维优化。详见[性能对比与回退记录](graph-ui-3d-drag-rollback-2026-11-12.md)。下文为历史实现和部署记录。

三维画布增加与二维类似的邻域联动：被拖节点沿当前屏幕平面跟随鼠标，相邻节点在三维力导向布局下弹性调整。松开后被拖节点固定，邻域继续收敛；重新布局保留已固定的位置。右键节点可以解除固定。

空白拖拽继续旋转视角，Shift 拖拽继续平移。三维深度、视角及缩放保留；鼠标位移通过当前相机投影换算。跟手更新使用绝对目标位置，避免 GPU 绘制较慢时排队回放每个鼠标事件。布局和绘制按帧合并，不逐帧更新 React 状态。

复用官方三维扩展内置的 D3 三维力引擎，拖动开始时同步节点当前位置和当前连接距离／斥力配置。场景销毁时停止模拟和待执行帧，移除布局监听器。

主要实现：`three-dimensional-physics.ts`、`three-dimensional-drag.ts`、`three-dimensional-input.ts`，由 `three-dimensional.ts` 接入。

16 项相关测试和生产构建通过。浏览器验证节点跟手、邻居移动、松开固定、重新布局保留固定和右键解除固定，无页面脚本异常。在真实 300 节点图谱旋转视角后，45／−30 像素的鼠标位移对应节点投影位移约 45.000004／−30.000003 像素。

本地检查程序、截图及结果位于 `data/browser-checks/graph-3d-elastic-20261111/`。
