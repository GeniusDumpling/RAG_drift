# 型号检索与问答召回修复（2026-10-21）

## 问题与原因

查询 `Mavic 3 Pro` 时，图谱可以找到实体及源内容，但普通检索被无关论坛回复或其他机型视频占据。正式库至少有五篇标题或正文明确包含该型号的内容，对应 29 个切片均标记索引成功。直接向量检索的前三条包含拆解视频、官方介绍和芯片指南，说明不能将问题归因于未采集或缺少向量。

原关键词检索按任意词子串匹配，`3`、`pro` 可命中回复序号和 `protocol` 等文本。多字段累加后大量候选达到 1.0，同分偏向新内容；混合分数再次封顶，挤掉了正确向量结果。视频结果先截取切片再去重，长视频还会占满名额。AI 问答共用此召回流程，因而拿到错误机型的证据。

另有历史视频向量只有内容 ID、视频链接和摘要，没有 `item_type`，因此类型筛选会漏掉本可召回的向量。内容详情和图谱按 ID 或实体别名读取，不经过上述排序。

## 修改

- 保留带编号和后缀的型号短语，支持中文问题中夹带英文型号；规则不依赖模型服务。
- 英文词采用边界匹配，数字及通用型号后缀降权。相同词命中多个字段只取最高字段权重，按查询覆盖度计算关键词分数。
- SQL 候选预选与 Python 评分共用词条、边界和权重，避免数据库截断前后排序标准不同。
- 混合排序保留向量相似度，对关键词单路结果折扣，并按两路支持程度加分。
- SQL 每篇保留两个高分候选切片；普通检索先按内容去重再截取，问答先覆盖不同内容，再允许每篇第二条证据。
- 放宽向量候选的类型条件以兼容缺少 `item_type` 的旧载荷，最终始终按 PostgreSQL 真实类型过滤。新视频采集代码补齐类型、来源、语言、标签和发布时间字段。
- 检索 trace 增加 `ranking_version=phrase-coverage-v1` 和 `model_phrases`。

没有更换嵌入模型、重建集合或修改已有向量。类型兼容不代表已补齐历史载荷中的来源、语言等其他字段；这些过滤仍需完整元数据。
