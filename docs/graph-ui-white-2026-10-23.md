# 白色交互图谱页面（2026-10-23）

当前正式版本已升级为 v8，图谱并入主应用内容区，保留统一左侧导航与系统顶栏，移除图谱专用顶部导航。白色主题和交互功能继续保留，见 [统一工作区部署记录](graph-ui-navigation-2026-10-23.md)。以下为 v7 白色主题发布记录。

正式页面仅保留 AntV G6 交互视图，已移除经典 SVG 画布、切换按钮、旧渲染器偏好读取和经典视图故障回退。即使浏览器之前保存了经典视图选项，也会直接进入交互图谱。画布加载或绘制失败时提供“重新加载页面”入口。

页面、画布、顶部导航和右侧数据面板改为白色背景，表单与统计卡片使用浅色底。实体类型配色、节点选中与悬停填色、连线的紫色高亮保持原值；文字和边框调整为适合白底的颜色，保证实体名称、关系标签与证据内容可辨认。

力导向布局、节点拖拽、悬停高亮、搜索、入链/出链、字幕证据和顶部导航保留。桌面默认 300 节点／500 关系、展开最多 500 节点／1,000 关系，以及移动端最多 150 节点／300 关系的预算保持不变；默认适应画布比例仍是缩小下限。
