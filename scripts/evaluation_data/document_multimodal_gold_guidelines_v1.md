# 官方手册图文证据 golden v1

固定来源：DJI Air 2S 中文手册 v1.0（2021.06）与 ANAFI Ai 英文指南 v7.7.1.7（2025-04-02）。19 个目标、4 个错误关联负例，由助手对照原始 PDF 初标，**用户已于2026-11-11确认人工复核完成**。标注内容与初标一致，仅更新复核状态，保留 v1。不包含全量实体与关系答案，不能据此报告全图精确率或 F1。

每组 `id` 对应选材清单的一类内容，可以包含多个物理页；运行时逐页抽取，通过 `group_id` 汇总评分。参数及灯态保留为事实属性，不把数值建立为实体。

| 字段 | 含义 |
|---|---|
| `manuals.sha256 / manual_version` | 必须匹配固定 PDF 及手册版本 |
| `source_hash` | 初次标注的解析包快照，不限制后续解析/切窗改进；评分绑定 PDF 哈希和手册版本 |
| `subject / object / attribute` | 可接受的原文名称，列表为同义或排版变体，大小写及空白不敏感 |
| `value_contains` | 可接受的值文本，任意一项匹配即可；允许保留原文额外条件 |
| `qualifier_contains` | 必须在结构化限定条件中保留的内容 |
| `evidence.page` | 从 1 开始的 PDF 物理页码，DJI 印刷页码少 1 |
| `text_contains` | 必须可定位的原生文字，允许事实与其端点实体的文字证据共同支持 |
| `bbox` | 目标图片在原页的范围，坐标归一到 0–1000；事实本身必须引用 IoU≥0.5 的区域 |
| `visual_label` | 图中真实编号；必须记录在事实证据中 |
| `led_pattern / operating_state` | LED1→LED4 的常亮/闪烁/熄灭，以及充电/查看电量/通电使用条件 |
| `negative_associations` | 人为替换成错误图片、灯态的候选，必须被独立审核或原文版面校验明确拒绝该事实，并分别报告拒绝来源 |

复核顺序：打开原文预览 → 按目标定位页码 → 核对原文值、单位、对象与条件 → 核对编号、图例和裁剪范围 → 确认负例确实错误。参考 `tools/document-knowledge-graph/review_sources.py` 生成预览。不要使用抽取结果或旧模型生成的图片描述反推答案。

评分分开报告目标事实召回、正确图文关联目标召回、已匹配目标预测的证据关联精确率、负例拒绝数。同一目标出现正确与错误两个预测时，错误预测也纳入关联精确率，且该目标不能算完整通过；其他未标注事实不自动算正确或错误。修改答案需记录原件依据并升版本，不能为贴合预测改标。
