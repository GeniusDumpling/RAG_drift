# 供应商页面按品牌浏览验证

2026-10-28。默认选择大疆，品牌选项来自数据库，当前包括大疆、Parrot、Skydio，也可选择全部品牌。以后有新品牌数据时无需修改前端枚举。

- 列表、搜索、分页和顶部统计均使用相同的 `buyer_name` 范围。
- 切换品牌清空搜索、回到第一页、关闭验证展开内容，忽略旧品牌迟到的列表、统计和验证响应。
- 表格展示采购方品牌；新增记录展示机型与证据年份，未知年份显示“未注明”。验证展开显示判定、时间、机型与年份，并保留原文链接。
- `GET /supplier/brands` 返回品牌及记录数；`GET /supplier/overview?buyer_name=Parrot` 与原有列表接口按品牌统计和筛选。省略品牌参数表示全部。
