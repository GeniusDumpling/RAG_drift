# Autel 官方资料采集（2026-11-12）

采集脚本：[tools/autel_documents](../tools/autel_documents/README.md)。默认输出目录：`data/Autel无人机文档`。

入口包括中英文官网的产品、下载中心、历史菜单，以及官方商店的历史支持页。PDF 覆盖 EVO、X-Star、EVO II 各代及行业/RTK 系列、EVO Nano、EVO Lite、EVO Lite 行业系列、EVO Max、Alpha、Dragonfish，以及遥控器、机巢、挂载、Mapper 和指挥中心等资料。手册、快速指引、维护手册、安全说明、发布记录、画册、产品清单和符合性声明按公开来源分别归档。

42 个资料分组中，29 个属于型号或系列入口，13 个属于配件或软件入口。中英文站和历史路由可能指向同一产品，不将这些数字解释成独立机型数。31 个参数入口也包含配件、软件及不同站点路由。

所有成功文件已重新读取并校验 SHA256；478 条 PDF 关联记录对应的文件全部经 PyMuPDF 实际打开验证，累计关联页数 13,774（共享文件重复关联计入，非去重页数）。31 个参数入口均通过现有 `DroneCatalogService` 读取，分组和参数数量与索引一致。14 项针对采集、续采、来源限制、元数据、参数适用条件及损坏文件识别的测试通过，Ruff 检查通过。

详细证据位于数据目录中的 `汇总.json`、`校验报告.json`、`兼容性校验报告.json`、`文档索引.csv`、`网页采集记录.csv`、`技术参数索引.csv`。可直接打开 `资料目录.html` 浏览本地 PDF。

失败清单保留 403、404 和一份截断、无法打开的旧版 EVO II 用户手册；这些内容不计入有效文件。文档中心为 JavaScript 动态目录，本工具未枚举其受限目录，使用公开官网链接发现文件。多列或合并参数表不猜测对应关系；无法直接转换的内容保留在原始 HTML，参数索引标为 `partial`。开发阶段遇到的无效占位链接和独立 SDK 采样页另存 `排除记录.json`，不计入本次结果。

```bash
.venv/bin/python -m tools.autel_documents verify
```
