## 访问与回退

- 预览地址：`http://localhost:18000/?view=VideoGraph`。
- 原版本：`http://localhost:8000`，进入“视频知识图谱”。远程访问时将 localhost 换成服务器地址。
- 预览页点击顶部“经典视图”，立即使用原来的 SVG 画布，保留当前节点、关系与证据；浏览器会记住选择。点击“切换为交互视图”可恢复 G6。
- 点击顶部“返回现有版本”可回到正式应用。
- 如要停用整个预览容器，在项目根目录执行：

```bash
bash scripts/g6-preview.sh rollback
```

该命令仅停止临时预览，不修改正式应用镜像、数据库或构图任务。再次启动：

```bash
bash scripts/g6-preview.sh start
# 查看临时容器状态
bash scripts/g6-preview.sh status
```

`start` 需要已安装前端依赖（首次可执行 `cd frontend && npm ci`），会构建静态前端和临时镜像。正式版本没有被此脚本切换，因此回退无需重启正式应用。

本次改版前的浅色 G6 预览镜像也已保存，可单独恢复该预览（只替换 18000 端口容器）：

```bash
G6_PREVIEW_IMAGE=rag-graph-g6-preview:before-obsidian-20261023 \
  docker compose --project-name rag-g6-preview -f docker-compose.g6-preview.yml \
  up -d --no-deps graph-preview
```

再次执行 `bash scripts/g6-preview.sh start` 会恢复当前源码对应的预览。

## 交互功能

- 全屏深色画布、小圆点实体、细连线与紫色高亮；顶部提供图谱探索、情报检索和工作台导航，离开图谱页后恢复原应用外观。
- 右侧数据面板可折叠，显示全局有效实体、关系、已构图视频、字幕证据和任务概况；底栏单独显示当前子图节点与连接数，避免与全局统计混淆。
- 数据面板支持实体类型、陈述状态和邻域层数筛选，以及当前视图的类型分组。
- 力导向布局与同心布局；默认对离散节点增加向心约束，避免视图缩得过小。
- 拖拽节点、平移画布、滚轮和按钮缩放、适应画布、重新布局。
- 按实体类型配色，并补齐国家、地区及地理关系的中文名称。
- 悬停节点时高亮入向和出向的一跳邻居及连接，无关节点保留 55% 透明度、连接保留 35%，底栏联动实体名称。移开后恢复完整亮度；正式 v2 已增加连线悬停高亮，不淡化全图。提示框显示完整名称及关系证据数。
- 点击实体打开“关联详情”，分别展示当前子图中的入链、出链和邻居数，可按方向筛选连接；这些计数不代表数据库中该实体的全部关系。
- 通过关联详情中的定位下拉框可使用键盘选中实体，按 `/` 聚焦顶部实体搜索，回车提交查询。
- 双击实体或点击“展开邻居”，调用现有接口并合并一跳结果，保留已有节点和关系；本地画面最多 150 个节点、300 条连接。
- 点击“聚焦此实体”，使用已有后端聚焦与 1～2 跳浏览能力。
- 点击关系联动字幕证据、视频时间链接和内容详情。
- 显示设置支持实体名称、关系方向箭头、节点大小及连线粗细；修改显示设置保留节点位置。布局引力提供斥力和连接距离滑块，调整后重新布局。
- 小屏默认收起数据面板，可从顶部按钮展开浮层。
- G6 加载或绘制失败时，提供经典视图恢复入口。

G6 按需加载，仅在选择交互视图后下载库文件。展开只读取现有图谱，不触发模型抽取。页面“刷新”会重新读取图谱，目前没有自动轮询或推送更新。

## 部署隔离

临时容器为 `intelligence-rag-g6-preview`，镜像为 `rag-graph-g6-preview:20261023`，使用显式独立 Compose 项目 `rag-g6-preview`。入口配置是 `docker-compose.g6-preview.yml`，脚本始终显式指定项目名，避免本机 `.env` 中的 `COMPOSE_PROJECT_NAME` 覆盖隔离设置。

临时容器使用 Python 静态服务与只读代理，将查询转发到现有 `intelligence-rag-app:8000`；不运行第二套后端、不执行迁移、不接收数据库凭据，也不挂载生产数据卷。仅允许 GET／HEAD，以及只读的 `POST /video-graph/retrieve`；其他写入请求直接返回 405。因此预览中的其他工作区用于浏览，新增任务等操作应到正式版本进行。

可选配置：

| 环境变量 | 用途 |
|---|---|
| `G6_PREVIEW_PORT` | 预览端口，默认 18000 |
| `G6_PREVIEW_BIND_ADDRESS` | 绑定地址，默认沿用 `APP_BIND_ADDRESS`，否则为 127.0.0.1 |
| `G6_PREVIEW_NETWORK` | 正式应用所在 Docker 网络，默认 `rag_drift_default` |
| `G6_PREVIEW_IMAGE` | 临时镜像标签 |

预览前记录的正式容器 ID、镜像名称和镜像 ID 位于 `data/g6-preview/baseline.json`；截图、浏览器检查和回退演练结果也保存在此目录，不随 Git 分发。

## 验证

已实际演练停止预览并恢复；正式容器 ID 和镜像始终与预览前一致。模拟 G6 脚本下载失败时，也可正常切换至经典画布。

已修复悬停结束后亮度残留的问题：G6 普通样式显式设置 `opacity: 1`，避免退出 `inactive` 状态后沿用淡化透明度。浏览器像素对比验证了移入空白处亮度不变、节点反复悬停后亮度完全恢复、悬停连线不触发全图淡化；报告位于 `data/g6-preview/hover-brightness-report.json`。

相关组件测试 10 项通过，代理隔离测试 5 项通过，TypeScript 与生产构建通过。真实 Chromium 验证了节点拖拽（实际移动约 114 像素）、悬停高亮、入链／出链筛选、显示开关即时重绘、引力与布局切换、搜索快捷键、字幕证据、顶部导航、经典视图切换和移动端面板。展开 DJI 邻居后从 80 个节点增至 123 个，原有节点均保留，页面无 JavaScript 异常。截图与详细报告位于 `data/g6-preview/obsidian-*.png` 和 `data/g6-preview/obsidian-browser-report.json`。

初次 G6 接入时的全量前端回归还发现检索、导航和文献页面的既有测试不匹配，以及本机开发 API 地址与某项测试默认值不一致；已使用原始版本和相同本机环境配置进行对照，原版本为 61 项通过、9 项失败，当时升级后为 64 项通过、同样 9 项失败。本次 Obsidian 风格改版另增加了 3 项组件测试，图谱相关 10 项独立通过；这些已有问题未混入本次升级修复。

G6 接入遵循 [官方 React 生命周期说明](https://g6.antv.antgroup.com/manual/getting-started/integration/react)，组件卸载时销毁画布与尺寸监听，防止切换视图后遗留实例。
