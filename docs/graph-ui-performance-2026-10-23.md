# 图谱展示数量与性能配置（2026-10-23）

当前正式图谱版本为 v14，支持工具栏切换 2D / 3D，点击节点后自动居中，三维画布围绕选中节点上下、左右连续旋转 360°，见 [3D 图谱说明](graph-ui-3d-2026-10-26.md)。两种模式都执行 [连通分量过滤与密集区域优先选取](graph-ui-connected-2026-10-26.md)，白色画布、统一左侧导航、铺满内容区的布局和本页数量限制保持不变；v9 布局发布记录见 [统一工作区部署记录](graph-ui-navigation-2026-10-23.md)。

正式图谱已从全量渲染改为限量概览，减少力导向计算、标签绘制和悬停高亮的开销。

| 场景 | 节点上限 | 关系上限 |
|---|---:|---:|
| 桌面端默认加载、搜索与聚焦 | 300 | 500 |
| 桌面端手动展开后的画布 | 500 | 1,000 |
| 移动端加载与手动展开 | 150 | 300 |

移动端以窗口宽度不超过 680px 判断；跨越断点时按当前搜索与筛选条件重新加载。数据面板展开或收起不会改变展示预算。数量是上限，并非保证填满关系数。

实体和关系继续保存在 Neo4j，展示限制不会删除数据。右侧统计显示全部有效图谱总量，画布及底栏显示当前概览数量。默认先过滤少于 5 个节点的独立子图，按核心连通程度、邻居数量与节点间已有连接优先选择区域，保留连通骨架后补充内部关系，不再补充孤立实体。搜索、类型与陈述筛选先限定候选范围，再执行同样的展示规则；筛选后不足 5 个节点的独立子图不会展示。

手动展开保留已显示节点，达到节点或关系上限后给出提示，新增节点随连线成对加入，避免连线预算耗尽后产生孤立点。力导向布局、节点拖拽、悬停高亮和字幕证据保留。默认适应画布的缩放比例继续作为缩小下限，允许放大后退回默认比例。

## 配置与接口

前端预算集中在 `frontend/src/components/video-graph/limits.ts`。页面初始查询使用对应的默认预算，展开查询和本地合并共同执行最大预算。

`GET /video-graph/graph` 默认 `max_nodes=300&max_edges=500&min_component_size=5`，显式参数最大允许 `max_nodes=500&max_edges=1000`。`min_component_size=0` 可关闭连通筛选；`full=true` 返回筛选范围内完整有效图谱，关闭展示筛选与数量截断。正式页面固定发送最小子图规模 5，不发送全量参数。GraphRAG 内部检索预算及小图可检索性未改变。
