# 知识视角切换与布局约束

本次修复针对视频知识图谱工作台的视角切换。发布镜像为 `rag-graph-lens-stable:20261119-v1`，基于当前正式镜像 `rag-graph-lenses:20261119-v1` 更新前端静态文件。

## 展示行为

- 切换知识视角或二维布局时，保持画布尺寸、缩放比例和平移位置；节点在约 650ms 内迁移到新的布局位置。
- 删除“精简聚焦”及范围模式切换，统一保留完整已加载子图，淡化当前视角以外的节点和关系。没有命中关系的视角仍保留全景画布并显示提示。
- 全景初始位置作为背景锚点，语义布局使用同一视野范围，避免切换时重新拉远相机。关联路径仍可经过背景节点。
- 切换视角或布局时清除节点固定坐标及残留速度；拖动后固定的节点会参与下一次布局。隐藏节点的缓存固定状态也会清除。
- 分栏节点在过渡完成后、力模拟每帧以及拖拽过程中受所属区域约束，计入节点半径和高亮余量。圆形结构同样限制节点落在所属圆内。
- 连续切换会取消旧迁移动画；过渡期间平移画布不会中断节点迁移。三维视角切换保留已有场景并通过状态淡化背景。

## 验证与发布记录

相关前端测试覆盖视角、展开收起、搜索、证据、二维交互及三维辅助逻辑，TypeScript/Vite 生产构建通过。真实浏览器使用正式数据库数据验证 300 个节点、500 条关系的四视角切换、手动缩放和平移、快速切换、拖拽后清除固定状态、分栏与圆形边界、重新布局、空视角背景、390px 手机布局及三维场景保留。

发布脚本先在 `127.0.0.1:18027` 启动隔离容器验证，再替换正式容器，并在正式页面重跑同样的浏览器检查。保留运行环境、端口、挂载及其他容器，关闭自动数据库迁移。
