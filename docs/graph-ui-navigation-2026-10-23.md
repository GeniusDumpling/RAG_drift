# 图谱接入统一工作区（2026-10-23）

视频知识图谱与供应链、AI 问答共用主应用左侧导航。v9 移除图谱页顶部“视频情报”“视频知识图谱”等标题、说明与系统顶栏，取消内容区外边距及宽度上限，图谱工作台铺满导航右侧的可用空间。保留搜索工具栏、白色画布、数据面板及底部状态栏。

## 查看方式

- 打开 `http://localhost:8000`，在左侧“工作空间”中选择“视频知识图谱”。
- 可直接使用左侧导航切换供应链、AI 问答和图谱，导航操作与其他工作区一致。
- 原直达链接 `http://localhost:8000/?view=VideoGraph` 继续有效，打开的也是带左侧导航的主界面。
- 全局侧栏仍可由用户手动收起或展开，画布随内容区宽度自动适应，并重新校准默认缩放下限。
- 较窄的内容区默认收起数据面板，打开时以浮层显示；移动端沿用主应用响应式导航，图谱填满导航下方剩余视口高度。
- 侧栏按钮位于画布上层，画布贴边时仍可收起和展开侧栏；切换至其他页面后恢复原系统顶栏与内容区留白。

白色背景、力导向布局、节点拖拽、悬停高亮、入链/出链、搜索和字幕证据保留。桌面默认 300 节点／500 关系、展开最多 500 节点／1,000 关系，移动端最多 150 节点／300 关系的预算保持不变；经典视图仍已移除。
