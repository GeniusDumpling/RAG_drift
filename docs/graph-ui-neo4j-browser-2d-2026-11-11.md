# Neo4j Browser 二维图谱展示（2026-11-11）

当前部署为 v2，名称自动显隐及逐帧更新优化见 [二维性能记录](graph-ui-2d-performance-2026-11-11.md)。下文保留 v1 实现与发布记录。

现有视频知识图谱的二维画布采用 SVG 和 D3 力导向布局，实现 Neo4j Browser 的圆形节点、圆内名称、关系方向、关系标签、交互式邻域探索与类型样式设置。依据 [图谱结果交互说明](https://neo4j.com/docs/browser/operations/result-frames/) 和 [图谱样式说明](https://neo4j.com/docs/browser/operations/browser-styling/)。

## 展示与操作

- 首次进入默认二维，已有浏览器维度偏好仍生效。
- 节点按实体类型着色，名称在圆内换行，长名称省略；悬停提示保留完整名称。关系越多节点越大，保留全局大小滑块。
- 关系从圆周连接，默认显示方向箭头和关系名称。平行关系、反向关系、自环独立呈现，字幕证据不合并。
- 点击节点查看已有实体详情，点击关系查看字幕证据。选中节点显示操作按钮，右键提供展开、固定／解除固定、隐藏等操作。
- 拖动节点后固定位置，重新布局保留固定节点。隐藏与撤销保留原有坐标和固定状态，只影响当前画布。
- 双击节点展开，再次双击收起。收起通过初始图谱和仍然展开的邻域重建结果，保留其他展开分支共享的节点及关系。
- 支持拖拽空白平移、滚轮缩放、放大／缩小和适应画布。
- 顶部类型标签支持节点颜色、大小和文字，以及关系颜色、线宽和文字设置。画布内查找高亮实体，支持 SVG 和 PNG 导出。

入口仍为 `?view=VideoGraph`，主要实现位于 `BrowserGraphCanvas.tsx`、`browser-geometry.ts`、`browser-graph.css`；邻域收起由 `VideoGraphPage.tsx` 管理。数据查询预算、筛选条件和字幕证据接口继续使用现有服务。

## 验证

38 项图谱前端测试与生产构建通过。真实浏览器覆盖多语言标题、平行／反向边、自环、节点选择、拖拽固定和解除固定、双击展开收起、隐藏撤销、字幕证据、类型颜色与查找、SVG／PNG 导出、平移缩放与适应画布、移动端布局及维度切换。真实数据检查展示 300 个节点、337 条关系，无页面脚本异常。
